# Техническая информация для работы

## Как подключиться к плате по SSH
К ней надо подключаться с ccfit. 
* Лучше настроить подключение по ключу ed25519, чтобы не вводить пароль каждый раз.
Для этого нужно исполнить команды:
1) ssh-keygen -t ed25519 Нужно нажать enter 3 раза, когда спрашивают ввести строку.
2) ssh-copy-id <Имя SSH хоста, к которому хотите подключаться без пароля>
Ввести пароль от пользователя на хосте платы.
Теперь можно подулючаться командой    ssh <Имя SSH хоста, к которому хотите подключаться без пароля>.
* Для того, чтобы  быстро подключаться к плате есть скрипт connect.sh - запуск скрипта подключает к плате через ccfit. Но он в гитигноре, чтобы айпи не попадали в репозиторий, поэтому его надо скачать с чата.
  
## Как будем компилировать код
На плате есть компилятор GCC, поэтому будем использовать его. У себя на компе компилируем с gcc и запускаем код, а потом то же самое на плате. Скрипт для компиляции будет отличаться у разных людей, поэтому он тоже в гитигноре, называется test.sh. Для компиляции на плате есть скрипт build.sh. Оба скрипта используюи переменные из скрипта private_config.sh и public_config.sh, первый из них содержит чувствительные данные и тоже в гитигноре.

## Как собрать библиотеку
Для того, чтобы не писать слишком много bash-скриптов (отдельно для сборки библиотеки, отдельно для компиляции (использования) библиотеки и т.д.), для удобства будем использовать **Makefile**.
Все файлы, необходимые для компиляции, лежат в папке *build/* (объектные файлы *.o*, статическая библиотека *libjpge.a*, все исполняемые файлы). Так как каждый может скомпилировать код у себя, нет никакого смысла посылать эти файлы в гит, поэтому я добавил их в гитигнор.
* Для создания статической библиотеки *libjpge.a* нам из исходников нужны лишь файлы *jpg/jpge.cpp* и *jpg/jpge.h*, для того чтобы у себя скомпилировать её, достаточно лишь из корня проекта запустить:
``` make
make library
```

## Как скомпилировать (использовать) библиотеку
* При подключении библиотеки *libjpge.a* нам станет доступна важнейшая функция для конвертации изображения в jpeg:
``` cpp
bool compress_image_to_jpeg_file(
    const char* pFilename,
    int width,
    int height,
    int num_channels,
    const uint8* pImage_data,
    const params& comp_params
);
```
Здесь:
* **pFileName** - путь и имя выходного jpeg-файла (куда записать хотим)
* **width** - ширина изображения в пикселях
* **height** - высота изображения в пикселях
* **num_channels** - количество цветовых каналов (так как мы работаем с RGB, то подставляем значение 3)
* **pImage_data** - указатель на массив пикселей изображения
* **comp_params** - параметры сжатия. Этот параметр можно не передавать в функцию, тогда по умолчанию значение качества m_quality будет равно 85
* Возвращает **true** если сжатие произошло успешно и **false** если неуспешно

Если нужно другое качество сжатия, например 25, то нужно использовать:
``` cpp
jpge::params params;
params.m_quality = 25;
```
Качество должно принимать целое значение от 1 до 100 включительно, где 1 - наименьшее качество (больше потери), а 100 - наибольшее качество (меньше потери).

И передать *params* в качестве последнего аргумента
Использование можно посмотреть в файле *src/test.cpp*, там изначально никакого изображения нет, большая часть кода - это генератор простой картинки с закатом и горами.
Для этого достаточно из корня проекта запустить:
``` make
make test
```
Все полученные сжатые изображения будут лежать в папке *output/*

## Как использовать библиотеку для реального изображения
Как я выше писал, в test.cpp не используется ни одного начального изображения.
В реальности у нас всегда будет исходное изображение, и мы должны его сжать.
Для этого вначале нужно из изображения получить массив пикселей исходного изображения.
Это реализуется с помощью функции stbi_load из файла *jpg/stb_image.c*:
``` cpp
stbi_uc* stbi_load(
    const char* filename,
    int* x,
    int* y,
    int* channels_in_file,
    int desired_channels
);
```
Здесь:
* **stbi_uc** - псевдоним для типа unsigned char
* **filename** - путь к исходному изображению
* **x** - указатель на int, куда функция запишет ширину изображения
* **y** - указатель на int, куда функция запишет длину изображения
* **channels_in_file** - указатель на int, куда функция запишет исходное количество цветовых каналов.
* **desired_channels** — сколько каналов нужно вернуть в загруженном изображении. Значение 3 означает RGB.

Если изображение загрузить не удалось, функция stbi_load возвращает nullptr.
Использование можно посмотреть в файле *src/photo_compressor.cpp*, эта программа создает jpeg независимо от формата исходного изображения, главное, чтобы stbi_load умел его читать.

Для этого достаточно из корня проекта запустить:
``` make
make photo
```
Исходные изображения должны находиться в папке *input/*

На данный момент реализован интерактивный интерфейс при запуске.
Вначале программа спросит, какой файл нужно сжать, надо указать только название файла с расширением (например, cat.jpg).
Далее программа выведет, успешно ли загрузилось сообщение.
Если успешно, то программа спросит, какой параметр качества надо использовать, нужно ввести целое число от 1 до 100.
Далее программа напишет, успешно ли создано сжатое изображение, и если успешно, напишет путь до файла (например, output/cat_q12.jpeg).

Изображения из папки *output/* я также добавил в гитигнор, ведь каждый может получить их у себя.
