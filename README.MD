# Техническая информация для работы

## Как подключиться к плате по SSH
К ней надо подключаться с ccfit. 
* Лучше настроить подключение по ключу ed25519, чтобы не вводить пароль каждый раз.
Для этого нужно исполнить команды:
1) ssh-keygen -t ed25519 Нужно нажать enter 3 раза, когда спрашивают ввести строку.
2) ssh-copy-id <Имя SSH хоста, к которому хотите подключаться без пароля>
Ввести пароль от пользователя на хосте платы.
Теперь можно подулючаться командой    ssh <Имя SSH хоста, к которому хотите подключаться без пароля>.
* Для того, чтобы  быстро подключаться к плате есть скрипт connect.sh - запуск скрипта подключает к плате через ccfit. Но он в гитигноре, чтобы айпи не попадали в репозиторий, поэтому его надо скачать с чата.
  
## Как будем компилировать код
На плате есть компилятор GCC, поэтому будем использовать его. У себя на компе компилируем с gcc и запускаем код, а потом то же самое на плате. Скрипт для компиляции будет отличаться у разных людей, поэтому он тоже в гитигноре, называется build.sh.
