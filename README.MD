# Техническая информация для работы

## Как подключиться к плате по SSH
1) Лучше настроить подключение по ключу ed25519, чтобы не вводить пароль каждый раз.
Для этого нужно исполнить команды:
1.1) ssh-keygen -t ed25519
Нужно нажать enter 3 раза, когда спрашивают ввести строку.
1.2) ssh-copy-id <Имя SSH хоста платы с именем пользователя>
Ввести пароль от пользователя на хосте платы.
Теперь можно подулючаться командой    ssh <Имя SSH хоста платы с именем пользователя>.

2) Для того, чтобы  быстро подключаться к плате есть скрипт connect.sh - такможно не вбивать команду каждый раз. Но он в гитигноре, чтобы айпи не попадал в репозиторий, поэтому его надо скачать с чата.
